# ctzd-kit

What every department's kit builds on, and what only kits import: the loader seam (`@loader`, `query`), the fakes
(each source's sample rows), the table store, the drivers (Oracle, SQL Server, REST, files), the delivery of each
source's secret, the source explorer behind `ctzd sources`, the kit contract's checks and the department skill
`ctzd sync` writes into apps. See PLAN.md section 7.
